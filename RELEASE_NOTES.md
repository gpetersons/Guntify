# USpot 1.1 · build 71

A maintenance release with the latest integrated USpot source and project documentation.

- Keeps your existing playback, Radio, personalization, Library and Android Auto features.
- Retains the same application ID and saved signing-key configuration for in-place updates.
- Includes the complete corresponding source, license and attribution notices.

Download **USpot.apk** and install it over your existing USpot app. Back up your data in Settings first; avoid uninstalling.

APK assembly and unit tests must pass before publication. Device playback and account-dependent behavior still require device testing.
